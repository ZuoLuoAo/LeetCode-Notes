# Python 字典

## 字典是什么

字典是键值对结构，形式 `{键: 值}`，用 `字典[键]` 取值。

## 按键排序

`sorted(字典)` 返回排好序的键列表；要键值对用 `sorted(字典.items())`。

```python
d = {"b": 2, "a": 1, "c": 3}
print(sorted(d))                    # ['a', 'b', 'c']：键排序
print(sorted(d.items()))            # [('a', 1), ('b', 2), ('c', 3)]
```

## 字典比较相等

用 `==`：键和值完全一样就相等，顺序无关。

```python
print({"a": 1, "b": 2} == {"b": 2, "a": 1})   # True：键值相同即相等，顺序无关
```

## 哈希表是什么

Python 里没有名叫「哈希表」的语法，它是一类容器的**实现名字**。你已经天天在用的 `dict`（字典）和 `set`（集合）就是 Python 的哈希表：字典是「一个键配一个值」，集合是「只装键、不装值」。

它解决的问题：列表按「第几个」存取，想按「内容」找东西，只能从头翻到尾。

```python
nums = [3, 8, 1, 9, 4]
print(9 in nums)      # True：最坏要把 5 个数逐个看完才知道
```

哈希表的想法是：先把「内容」算成一个编号（哈希函数），拿编号直接当存放位置用，就能一步定位，不用翻。

```python
d = {3: "a", 8: "b", 1: "c", 9: "d", 4: "e"}
print(d[9])           # "d"：算一下 9 的位置就拿到了，跟表里有多少项无关
```

所以哈希表 = 数组 + 哈希函数 + 冲突处理（两个不同的键算出同一个位置时怎么安置）。查找、插入、删除平均都是 O(1)。

「哈希表的定义」不是一段要背的代码，而是这种「用键算出存放位置」的做法；Python 已经照这个做法把容器做好给你了，名字就叫 `dict`——你写 `{...}` 的时候，就是在用一个哈希表，不需要自己写哈希表。

要点：

- 键必须可哈希（不可变类型）：数字、字符串、元组可以，列表不行。
- 平均 O(1)，运气极差（哈希冲突扎堆）时单次会退化成 O(n)。
- 代价是占内存，换来的是「知道键就能一步找到它」。
- Python 3.7 起 dict 还保持插入顺序。

用法就是字典和集合那套：建、增／改、查、判存在、删、数个数、遍历。

```python
cnt = {}                  # 建一个空字典（哈希表）
cnt["a"] = 1              # 增／改：把键 "a" 的值设成 1
print(cnt["a"])           # 查：按键取值
print("a" in cnt)         # 判存在
print(cnt.get("b", 0))    # 取值，没有这个键就给默认 0
del cnt["a"]              # 删
print(len(cnt))           # 键的个数
for k, v in cnt.items():  # 遍历键值对
    print(k, v)
```

计数是它最常用的第一招，本题用的就是这一招：键放元素，值放出现次数。

```python
cnt = {}
for x in [1, 2, 1, 3]:
    cnt[x] = cnt.get(x, 0) + 1     # 见过就 +1，没见过从 0 起算

print(len(cnt))           # 3：有几种不同的数
```

## defaultdict(int) 是什么

`cnt = defaultdict(int)` 的意思是：造一个空字典（哈希表），并给它加一条规则——碰到没见过的键，就当它的值是 0。

```python
from collections import defaultdict

cnt = defaultdict(int)
cnt["a"] += 1        # "a" 还不存在？先自动补 0，再 +1
print(cnt["a"])      # 1
print(cnt["zzz"])    # 0：读不存在的键也会自动补一个 0
```

拆开看：

- `cnt`：变量名，count 的缩写，随便改。
- `=`：赋值，把右边造好的字典交给 `cnt`。
- `defaultdict`：`collections` 里的类，是字典的扩展版，所以必须 `from collections import defaultdict` 才能用（题解里常省略这行）。
- `(int)`：括号里是「缺键时拿什么造默认值」——`int` 是可调用的类型，`int()` 正好得 `0`，所以默认值是 0；想换默认值就换成 `lambda: 100` 之类。

不导入任何东西的等价写法：`cnt[x] = cnt.get(x, 0) + 1`。

注意：读一个不存在的键会把那个键以 0 存进字典，所以拿 `len(cnt)` 当「种类数」用时得留意；本题只在加减计数时用它，而且计数减到 0 会 `del`，不受影响。

## 不用 defaultdict 怎么给字典设默认值

`defaultdict` 唯一的作用，就是省掉「读不到键时自己给默认值」这一步。不用它有这么几种写法：

取值给默认（最常用）：

```python
cnt = {}
cnt[x] = cnt.get(x, 0) + 1     # 没有 x 就当它是 0，再 +1
```

先判断、再初始化：

```python
if x not in cnt:
    cnt[x] = 0
cnt[x] += 1
```

`setdefault`：没有就设成默认值，并返回这个值：

```python
cnt[x] = cnt.setdefault(x, 0) + 1
```

键已存在时它返回当前值、不覆盖（`cnt.setdefault("a", 999)` 不会把原来的 1 改成 999）。

键的集合事先就知道，可以一次铺好：`cnt = dict.fromkeys("abc", 0)` 得到 `{'a': 0, 'b': 0, 'c': 0}`。

计数还有专用的 `collections.Counter`：

```python
from collections import Counter
c = Counter()
c["x"] += 1        # 缺键也当 0
```

但 Counter 有两个区别：读不存在的键返回 0，却不把这个键存进去；计数减到 0 时键也不会自动删掉（`len` 会把它算上）。所以本题「用 `len(cnt)` 当种类数」的写法不能用 Counter。

本题里 `cnt[x] += 1`、`cnt[out] -= 1` 的手工等价版：

```python
cnt[x] = cnt.get(x, 0) + 1
cnt[out] = cnt.get(out, 0) - 1
if cnt[out] == 0:
    del cnt[out]
```

## 统计键的个数

用 `len(字典)`，它就是键的个数（字典不允许重复键，所以键数 = 键值对数），O(1)。

```python
cnt = {"a": 1, "b": 2}
print(len(cnt))          # 2
cnt["c"] = 0
print(len(cnt))          # 3：值为 0 的键照样算一个
print(len(cnt.keys()))   # 3：等价写法，但没必要绕这一圈
```

两点容易踩：

- `len` 只数键，不数值。想数值的和用 `sum(cnt.values())`。
- 它数的是「还在字典里的键」。想数「计数不为 0 的键」得自己筛（`sum(1 for v in cnt.values() if v)`）——这正是本题里计数减到 0 必须 `del` 的原因。

## 计算值的和

用 `sum(字典.values())`。`values()` 返回的是「值的视图」，可以直接喂给 `sum`，不用先转成列表。

```python
cnt = {"a": 1, "b": 2}
print(sum(cnt.values()))      # 3
print(sum({}.values()))       # 0：空字典不报错（sum 从 0 起加）
```

别写成 `sum(cnt)`：那是对**键**求和。键不是数字会直接报错（`sum({"a": 1})` → TypeError: unsupported operand type(s) for +: 'int' and 'str'），就算键是数字，拿到的也是键的和，不是你要的值。

补充两点：

- 有几个键就要走几个，是 O(n)；不像 `len` 是一步到位。
- 值是计数时（`Counter` 或本笔记里的计数字典），`sum(cnt.values())` 是「元素总个数（含重复）」，`len(cnt)` 是「不同元素个数」——这两个正好配成一对。
