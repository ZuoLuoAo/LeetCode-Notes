# Python 字典

## 字典是什么

字典是键值对结构，形式 `{键: 值}`，用 `字典[键]` 取值。

## 提取所有键

用 `keys()`：`字典.keys()` 返回所有键。

返回 `dict_keys` 视图对象，不是列表；可直接迭代、用 `in` 判断，需列表时用 `list(字典.keys())` 转换。

## 按键排序

`sorted(字典)` 返回排好序的键列表；要键值对用 `sorted(字典.items())`。

```python
d = {"b": 2, "a": 1, "c": 3}
print(sorted(d))                    # ['a', 'b', 'c']：键排序
print(sorted(d.items()))            # [('a', 1), ('b', 2), ('c', 3)]
```

## 字典比较相等

用 `==`：键和值完全一样就相等，顺序无关。

```python
print({"a": 1, "b": 2} == {"b": 2, "a": 1})   # True：键值相同即相等，顺序无关
```
