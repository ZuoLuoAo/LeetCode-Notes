# Python 集合

## 集合是什么

集合（`set`）是一组**无序、不重复**的元素，核心用途：去重 + O(1) 成员判断。

```python
s = {1, 2, 3}          # 直接创建集合
s = set([1, 2, 2, 3])  # 从列表创建，自动去重
print(s)               # {1, 2, 3}
```

要点：

- 空集合必须写 `set()`；`{}` 是空字典。
- 元素必须可哈希：数字、字符串、元组可以；列表、字典不行（TypeError）。
- 常用操作：`x in s` 判断存在；`s.add(x)` 添加；并集 `s | t`、交集 `s & t`、差集 `s - t`、对称差 `s ^ t`。
- 无序：不能 `s[0]` 按下标取值；要排序用 `sorted(s)`。

## 自动去重

集合 `set` 自动去重，但不保证排序；要排序去重用 `sorted(set(列表))`。

```python
lst = [3, 1, 2, 1, 3]
s = set(lst)
print(s)                    # {1, 2, 3}：去重，但顺序不保证
print(sorted(set(lst)))     # [1, 2, 3]：去重且升序
```

会自动去重的类型：集合 `set`（元素唯一）；字典的键也唯一，重复赋值会覆盖。列表、元组、字符串都不去重。

```python
print(set([1, 2, 2, 3]))   # {1, 2, 3}：自动去重

d = {"a": 1, "a": 2}
print(d)                   # {'a': 2}：键唯一，后写的覆盖前一个
```
