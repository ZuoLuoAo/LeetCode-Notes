# Python 列表

## 列表排序

用 `sort()`（原列表排序）或 `sorted()`（返回新列表）；默认升序，数字按大小、字符串按字符编码顺序；`reverse=True` 降序，`key=` 自定义规则。

```python
nums = [3, 1, 2]
nums.sort()                     # 原地排序 → [1, 2, 3]
b = sorted(nums)                # 返回新列表
c = sorted(nums, reverse=True)  # 降序 → [3, 2, 1]
```

字符串按字符编码顺序排：`['a', 'b', 'c']` 本来就是升序，排序后不变。

`sort()` 原地排序、返回 None，不能把返回值赋给变量；想要返回新列表用 `sorted()`。

```python
x = [3, 1, 2].sort()
print(x)        # None：sort() 不返回值

nums = [3, 1, 2]
nums.sort()     # 正确用法：先原地排序，再用原变量
print(nums)     # [1, 2, 3]

y = sorted([3, 1, 2])   # 想要返回新列表用 sorted()
print(y)        # [1, 2, 3]
```

## 列表比较

从左到右逐个元素比，第一对不同就出结果；前面全相同则短的更小。

判断是否相等用 `==`：元素和顺序都相同才相等。

```python
[1, 2, 3] < [1, 3, 0]   # True：第 2 位 2 < 3
[1, 2] < [1, 2, 3]      # True：前缀相同，短的更小
[1, 2, 3] == [1, 2, 3]  # True：元素和顺序都相同
[1, 2, 3] == [3, 2, 1]  # False：顺序不同
```

## 判断列表是否为空

用 `if not 列表:`，或 `len(列表) == 0`。

```python
lst = []
if not lst:
    print("空列表")       # 常用写法
if len(lst) == 0:
    print("空列表")       # 等价写法
```
