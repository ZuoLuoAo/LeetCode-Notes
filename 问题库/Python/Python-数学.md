# Python 数学

## 除法向上取整

用 `math.ceil(a / b)`，或 `-(-a // b)`。

```python
import math
print(math.ceil(7 / 2))    # 4
print(-(-7 // 2))          # 4
```

原理：`a // b` 是向下取整；`-(-a // b)` 先取负再向下取整、再取负，等价于向上取整，即 `向上取整(a/b) = -向下取整(-a/b)`。

`//` 是整除（结果向下取整），`/` 才是普通除法（结果是浮点数）。

```python
print(7 / 2)    # 3.5，普通除法
print(7 // 2)   # 3，整除
print(-7 // 2)  # -4，整除会向下取整（-3.5 → -4）
```
