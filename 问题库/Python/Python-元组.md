# Python 元组

## 元组是什么

元组是类似列表的有序集合，区别是不可变：创建后不能增删改元素。用圆括号 `()` 表示。

```python
t = (1, 2, 3)
print(t[0])        # 1，可以索引
# t[0] = 9         # 报错：元组不可修改
a, b, c = t        # 可以解包 → a=1, b=2, c=3
```

性质：有序、不可变、可索引、可遍历、可作字典的键。

列表转元组用 `tuple(列表)`：顺序不变，重复数据保留。

```python
lst = [3, 1, 2, 1]
t = tuple(lst)
print(t)    # (3, 1, 2, 1)：顺序不变，重复的 1 还在
```
