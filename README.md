>
> English: A personal LeetCode study journal — my first-accepted code vs official editorials, with comparison and reflection, powered by Obsidian (Python & C++).

## 使用说明

1. 用 Obsidian 打开本仓库根目录作为 Vault。
2. 做新题：在题单对应的章节（小节）目录下新建 `LCxxxx-题目名/README.md`，按统一模板填写。
3. 我的代码从 LeetHub 私有仓库（`LeetCode-Raw`）原样内嵌，一字不改；官方题解标注来源。
4. 做题中的问题收录到 `问题库/`，累计提问次数与出现次数。

## 刷题方法

- 先独立思考 5-10 分钟；无思路再看题解或请教 AI。
- 看懂后独立重写一遍，确保真正掌握。
- 按专题刷，不随机刷：同一个套路可以一次解决多题，也更容易看清算法的本质。
- 螺旋上升：先把各题单 ≤1700 的基础题刷一遍，再回头刷更难的。
- 每周每个主题吃透 3~5 道经典题，在专题总结中标记模板题。
- 高频问题即薄弱点：优先复习 `问题库/00-索引.md` 中计数最高的条目。

## 规范速览

- 命名：题单 `01-滑动窗口`；章 `01-定长滑动窗口`；节/小节 `01-基础`；题目 `LC0001-两数之和`；问题 `Python-xxx.md`

- 状态：`初次` / `复习中` / `已掌握`
- 提交：Conventional Commits（英文 type + 中文描述），如 `feat: 新增 LC0001 两数之和`
- 红线：未 AC 不入库；内嵌代码与 LeetHub 原始提交一致；无个人信息与密钥
