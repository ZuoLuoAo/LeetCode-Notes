## 一道题怎么记

每题一个 `LCxxxx-题目名/` 目录，里面是代码加一份 `README.md`：

| 文件 | 内容 |
| --- | --- |
| `solution.py` | 我的答案；重刷存成 `solution-v2.py` |
| `editorial.py` | 官方题解；多个方法存成 `editorial-方法名.py`，C++ 存 `.cpp` |
| `README.md` | 题目 → 我的代码 → 官方题解 → 对比 → 复盘 → 复习记录 |

- 「对比」只写我和官方的差距，不重抄上面的代码。
- 「复盘」每个结论只写一次，固定四栏：核心思路、踩的坑、学到的、关联问题。
- 代码按空行分块，每块开头单独一行注释说明这块在干什么。
- 重刷不去改第一次的记录，在「我的代码」下追加 `### 第二次 AC（日期）`，并在「复习记录」补一行。
