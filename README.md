# LeetCode 刷题笔记

> 个人 LeetCode 刷题记录与复盘：每题整合"我的第一次 AC 代码 + 官方题解 + 代码对比 + 复盘"，与 Obsidian 联动，公开在 GitHub。
>
> English: A personal LeetCode study journal — my first-accepted code vs official editorials, with comparison and reflection, powered by Obsidian (Python & C++).

## 使用说明

1. 用 Obsidian 打开本仓库根目录作为 Vault。
2. 做新题：在对应主题目录新建 `LCxxxx-题目名/README.md`，按统一模板填写。
3. 我的代码从 LeetHub 私有仓库（`LeetCode-Raw`）原样内嵌，一字不改；官方题解标注来源。
4. 做题中的问题收录到 `问题库/`，累计提问次数与出现次数。

## 刷题方法

- 先独立思考 5-10 分钟；无思路再看题解或请教 AI。
- 看懂后独立重写一遍，确保真正掌握。
- 每周每个主题吃透 3~5 道经典题（Medium），在专题总结中标记模板题。
- 高频问题即薄弱点：优先复习 `问题库/00-索引.md` 中计数最高的条目。
