# 12-字符串 · 专题总结

## 一句话本质

字符串问题大多围绕"遍历/模拟 + 拼接"，核心是索引控制和拼接效率。

## 应用场景

- 按规则交替/合并/变换字符（如 [[LC1768-交替合并字符串]]）
- 查找子串（[[LC0028-找出字符串中第一个匹配项的下标]]）、回文、前缀等

## 常用套路 / 模板要点

- 双索引同时遍历：`for i in range(max(m, n)): if i < m ... if i < n ...`
- Python 交替合并：双指针 `while i < m or j < n` 依次取字符（或 `zip_longest` 一行）
- 拼接用 `''.join(列表)`，不用逐字符 `+`
- 字符串匹配：暴力枚举起点 + 逐位比较（`for-else` 收尾）；进阶 KMP 让主串指针不回退

## 经典题

- [[LC1768-交替合并字符串]]（模拟入门）
- [[LC0028-找出字符串中第一个匹配项的下标]]（字符串匹配入门）

## 常见误区

- 重复计算长度、手动造 range 步长
- 循环内字符串 `+` 拼接导致低效
- 直接访问 `needle[0]` 前未确认题目是否允许空串
