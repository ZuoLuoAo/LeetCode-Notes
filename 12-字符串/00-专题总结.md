# 12-字符串 · 专题总结

## 一句话本质

字符串问题大多围绕"遍历/模拟 + 拼接"，核心是索引控制和拼接效率。

## 应用场景

- 按规则交替/合并/变换字符（如 [[LC1768-交替合并字符串]]）
- 查找子串、回文、前缀等

## 常用套路 / 模板要点

- 双索引同时遍历：`for i in range(max(m, n)): if i < m ... if i < n ...`
- Python 交替合并：`zip_longest(..., fillvalue='')`
- 拼接用 `''.join(列表)`，不用逐字符 `+`

## 经典题

- [[LC1768-交替合并字符串]]（模拟入门）

## 常见误区

- 重复计算长度、手动造 range 步长
- 循环内字符串 `+` 拼接导致低效
