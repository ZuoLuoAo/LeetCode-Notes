## 对比

思路差别：我用两个字典分别统计 `s` 和 `t`，最后比较两个字典是否相等；官方方法二只用一个字典，遍历 `s` 时加一、遍历 `t` 时减一，某个字符被减成负数就说明 `t` 里有 `s` 没有的字符，直接返回 False。

写法差别集中在三处：计数、长度判断、收尾。这里不重抄一遍，直接对着上面两块代码看——同一道题同一个方法，官方 12 行，我 24 行，多出来的全是这三处的啰嗦。

复杂度：我的和官方方法二都是 O(n) 时间、O(1) 空间（字符集只有 26 个小写字母）；官方方法一排序是 O(n log n)。

## 复盘

- **核心思路**：判断"重排"就是判断每个字符出现的次数是否相同。看到"异位词 / 重排 / 组成"这类字眼，先想哈希表计数。
- **踩的坑**：计数写成"首次出现记 0、之后再 +1"，算出来的其实是"出现次数减一"。结果虽然对，但跟自己脑子里"统计次数"的模型不符，回头读代码还得重新推一遍。以后一律 `dic[i] = dic.get(i, 0) + 1`。
- **学到的**：字典比较 `==` 只看键值、跟顺序无关，"两边内容是否为重排"这类判断直接用得上；`return 表达式` 比 `if/else: return True/False` 更短，也不会写反。
