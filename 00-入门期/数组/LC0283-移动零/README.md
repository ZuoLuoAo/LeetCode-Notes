## 对比

思路差别：我先数出一共有几个 0，再回头把遇到的 0 一个个冒泡到后面去。官方反过来——用一个变量记住"非零元素堆到哪了"，每个非零元素直接搬到那个位置，扫完一遍，剩下的位置全填 0。

写法差别：我 24 行、两层循环；官方 9 行、两趟平扫。我这版每遇到一个 0 都要把后面一整段往左挪一格，最坏 O(n²)；官方每个元素只搬一次。

复杂度：我是 O(n²) 时间、O(1) 空间；官方 O(n) 时间、O(1) 空间。这题数据范围小，我那样写也能过，但差的是一整个数量级。

## 复盘

- **核心思路**：原地整理数组时，换个方向想可能更省事——别盯着要挪走的元素（0），盯着要保留的元素（非零），一遍扫完就各自归位。
- **踩的坑**：① 结尾残留了一行 `print(nums)`，提交时带上了（收录时已从代码里删掉）；② "数 0 个数 + 逐个冒泡"这套写法，每个 0 都要把后面一整段整体挪一格，复杂度白白升到 O(n²)。
- **学到的**：`nums[i], nums[j] = nums[j], nums[i]` 一步就能交换两个元素，不用临时变量；另外"边扫边往前写"这个模式以后写数组题会反复用到。
