# 02-哈希表 · 专题总结

## 一句话本质

哈希表（Python 字典）用键直接定位值，是"空间换时间"：查找、插入都是 O(1)。

## 应用场景

- 统计字符/元素出现次数（计数），如 [[LC0242-有效的字母异位词]]、[[LC0389-找不同]]
- 判断元素是否存在、去重
- 用键快速查找配对（两数之和类）

## 常用套路 / 模板要点

- 先比长度/数量，再统计：`if len(s) != len(t): return False`
- 计数首选 `dict.get(key, 0) + 1`，避免先 `in` 再分支赋值
- "一个表双向用"：一个串计数加、另一个串减，出现负数即失败
- 比较两个计数结构：`dic_s == dic_t`（顺序无关）
- 求"多出来的那一个字符"：计数抵消 / ASCII 求和 / 异或三种思路

## 经典题

- [[LC0242-有效的字母异位词]]（计数 + 排序比较）
- [[LC0389-找不同]]（计数 / 求和 / 异或）

## 常见误区

- 先 `if key not in dic` 再赋值，不如 `dict.get(key, 0)` 一步完成
- 忘记处理"键存在但值不同"的情况（如 LC0389 中新增字符已在原串出现过）
- 排序后比较可行，但复杂度 O(n log n)，计数是 O(n)
